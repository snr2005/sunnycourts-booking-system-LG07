# SunnyCourts Club - Court Booking System

Backend Development Fundamentals (BDF) Group Assignment - ST-CSE2D-G07
Theme 7: Court Booking (SunnyCourts Club)

## Project Overview
SunnyCourts Club currently struggles with whiteboard-based court bookings where names get rubbed out and slot conflicts occur. This system provides a robust Express REST API backed by an SQLite database with validation, search capabilities, and the **"Three at a time"** active reservation limit.
